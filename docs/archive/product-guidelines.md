# Product Guidelines

## Prose Style
- **Tone:** Professional, Efficient, and Direct.
- **Voice:** Technical and authoritative but accessible. Avoid marketing fluff; focus on utility and clarity.
- **Terminology:** Use standard sysadmin and DevOps terminology correctly.

## Visual Identity & Design Principles
- **Theme:** Dark-mode first. Designed for low-light environments and long usage sessions to reduce eye strain.
- **Layout:** High density, low chrome. Maximize screen real estate for the active workspace (terminals, remote sessions). Minimize padding and decorative elements.
- **Interactions:**
    - **Keyboard Centric:** Heavy emphasis on keyboard shortcuts (e.g., `Cmd/Ctrl+K` for command palette) for power users.
    - **Visual Feedback:** Use color coding (Green/Yellow/Red) and subtle animations (e.g., pulses) for real-time status updates without distracting from the main task.
- **Typography:** Use monospaced fonts (e.g., JetBrains Mono, Fira Code) for all code, logs, and terminal outputs. Clean sans-serif for UI elements.

## User Experience (UX)
- **Speed is a Feature:** Interactions should feel instantaneous. Startup time and connection speed are critical metrics.
- **Local-First:** All data is stored locally. No cloud dependencies for core functionality.
- **Privacy by Design:** AI features are opt-in and local-only. Credentials are encrypted and never leave the device.
